## Produrre la documentazione con Doxygen

### Prerequisiti

- Doxygen;

Solamente per la generazione delle immagini corrispondenti alle formule matematiche:

- Inkshape oppure pdf2svg;
- Gostscript;
- Latex.

### Produrre la documenazione senza i prerequisiti per le formule matematiche

Modificare la configurazione di Doxygen attivando l'uso della libreria MathJax:
nella sezione HTML impostare su YES l'opzione USE_MATHJAX.
